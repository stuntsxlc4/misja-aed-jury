# Polski lektor instrukcji

Pięć plików MP3 zawiera polski odczyt pięciu kroków z `web/src/features/rescue/steps.ts`. Odtwarzacz korzysta z nagrań, gdy system nie udostępnia polskiego głosu lub zgłosi błąd syntezy. Każde nagranie wycisza się po zmianie kroku lub opuszczeniu widoku.

Nagrania wygenerowano lokalnie z użyciem Piper 1.8.0 i polskiego głosu Darkman Medium. Karta modelu podaje licencję CC0 zbioru treningowego i bazowego głosu. [Karta modelu Piper](https://huggingface.co/rhasspy/piper-voices/blob/main/pl/pl_PL/darkman/medium/MODEL_CARD)
